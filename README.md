# CustomWings（自定义翅膀）

Minecraft Java **1.20.1 Forge** 客户端模组：给你的角色背后装上一对**会扇动的能量之翼**。
纯客户端渲染——**只有你自己可见**，任何世界/服务器通用，服务器与其他玩家零感知。

## 效果

- 🦋 一对从背部伸展的能量翼，持续**扇动动画**（开合 + 上扬）
- 🌈 默认**彩虹循环配色**（贴图本身是紫青渐变羽毛纹理，颜色作为染色叠加）
- 🪂 滑翔（鞘翅飞行）时双翼**自动全展**
- 📏 支持调节翅膀大小、扇动速度、配色

## 使用

1. 把 `customwings-1.0.0.jar` 放进 `.minecraft/mods/`（Forge 1.20.1）
2. 按 **F5** 切到第三人称即可看到翅膀
3. 游戏内指令：

| 指令 | 说明 |
|---|---|
| `/customwings toggle` | 开/关翅膀 |
| `/customwings color rainbow` | 彩虹循环配色 |
| `/customwings color #FF8800` | 固定颜色（十六进制） |
| `/customwings size 1.2` | 翅膀大小（0.3~3.0） |
| `/customwings speed 0.12` | 扇动速度（0.01~1.0） |
| `/customwings reload` | 重读配置文件 |

配置文件位于 `config/CustomWings/settings.txt`（首次启动自动生成）。

## 常见问题

- **第一人称看不到？** 正常现象——翅膀在你背后，按 F5 第三人称查看。
- **服务器会封吗？** 这是纯客户端视觉模组，不发送任何额外网络包，与披风/皮肤模组同类。
- **和 CustomCape / CustomSkin / CustomFX 冲突吗？** 不冲突，可叠加使用组成全套角色自定义。

## 构建

推送至 GitHub 后，Actions 自动构建（JDK 17 + Gradle 8.1.1），在构建页底部 Artifacts 下载 jar。
打 `v*` 标签会自动创建 Release。
